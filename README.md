# 🏧 ATM Simulation System (Based on Logic Flowchart)

Ushbu loyiha bankomat tizimining mantiqiy sxemasi (Flowchart) asosida yaratilgan **Python** dasturidir. Dastur terminal orqali ishlaydi va bankomatning barcha asosiy funksiyalarini korsatib  beradi.


## 🚀 Imkoniyatlar
Dastur sxemadagi quyidagi barcha bo'limlarni qamrab oladi:
* **Kirish:** Ko'p tilli menyu (Uzbekcha, Ruscha, Ingilizcha).
* **PIN Tekshiruvi:** 3 martalik urinish va xato kiritilganda bloklash tizimi.
* **Bosh Menyu:**
    * 💰 **Balans:** Joriy mablag'ni ko'rish.
    * 💸 **Naqd pul:** 50, 100, 150, 200, 300, 400 ming so'mlik tayyor variantlar va ixtiyoriy summa kiritish.
    * 📱 **Mobil aloqa:** Uzmobile, Beeline, Ucell, UMS, Perfectum uchun to'lov (summa kiritish imkoniyati bilan).
    * 🏢 **To'lovlar:** Komunal xizmatlar va Kredit to'lovlari mantiqi.
    * 🔐 **Xavfsizlik:** PIN-kodni o'zgartirish va SMS xabarnomani boshqarish.

## 🛠 Ishlatilgan Texnologiyalar
* **Til:** Python 3.10+
* **Operatorlar:** `if`, `elif`, `else`
* **Sikllar:** `while True` (Dasturning davomiyligini ta'minlash uchun)
* **Kutubxonalar:** `time` (Haqiqiy jarayon effektini berish uchun)
